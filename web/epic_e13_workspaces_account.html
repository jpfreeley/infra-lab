Acceptance Criteria

  • Route tables configured: private → NAT, public → IGW
  • Default security group restricted (no ingress/egress) per CKV2_AWS_12
  • VPC flow logs enabled, shipped to central log bucket

  • CIDR plan updated in docs/networking-cidr-plan.md
Subtasks
