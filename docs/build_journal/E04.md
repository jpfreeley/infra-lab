# Epic E04: Identity + Access + CI/CD Auth

## Overview

Epic E04 establishes the identity and access management framework for the infra-lab organization. This includes IAM Identity Center configuration, role-based permission sets, GitHub OIDC integration for keyless CI/CD, and IAM hardening controls.

---

## Stories Completed

### E04-S001: Enable IAM Identity Center

* IAM Identity Center was already enabled via Control Tower.
* Identity source: Built-in Identity Center directory.
* SSO Start URL: `https://jpf321.awsapps.com/start/`
* Identity Store ID: `d-906704ba3c`

### E04-S002: Create Permission Sets

* Deployed 5 role-based permission sets:

| Permission Set | Policies | Session | Purpose |
| -------------- | -------- | ------- | ------- |
| AdministratorAccess | AdministratorAccess | 4h | Break-glass, org management |
| PlatformEngineer | PowerUserAccess + IAMReadOnly | 8h | Infrastructure management |

### E04-S005: GitHub OIDC Provider

* Created OpenID Connect identity provider for GitHub Actions
* URL: `https://token.actions.githubusercontent.com`
* Client ID: `sts.amazonaws.com`
* Eliminates need for long-lived AWS credentials in CI/CD
