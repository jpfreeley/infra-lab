# Epic E11: FinOps

## Overview

Epic E11 adds per-environment cost visibility and alerting on top of the org-level
budgets established in E03. Cost allocation tags are enforced via the existing
tag policy (E03-S020) and module conventions (common_tags pattern).

---

## Stories Completed

### E11-S001: Cost Allocation Tags Across IaC

**Status**: Already implemented via existing infrastructure.

Tag enforcement is layered:

1. **Org-level tag policy** (E03-S020): Enforces `Project`, `ManagedBy`, `Environment`
   with controlled values on 6 resource types
1. **Provider default_tags** (providers.tf): `Project`, `Environment`, `ManagedBy`, `Owner`
   applied to all resources automatically
1. **Module common_tags** (locals.tf): Every module receives `local.common_tags`
1. **Cost Explorer activation**: Tags activated for cost allocation in billing console

No additional Terraform needed — the convention is established and enforced.

---

### E11-S002: Budgets + Alerts per Account/Env

- **Monthly dev budget**: $100/mo total, filtered by `Environment=dev` tag
  - Forecasted 50% alert
  - Actual 80% alert
  - Actual 100% alert
- **Compute budget**: $50/mo for ECS/Fargate services
- **Database budget**: $100/mo for RDS services

Budget alerts go to email. Future: integrate with SNS → Slack/Teams.

---

### E11-S003: Cost Anomaly Detection

- **Service-level anomaly monitor**: Tracks cost anomalies by AWS service
- **Daily anomaly subscription**: Alerts when anomaly impact >= $10
- Complements budgets by catching unexpected spending patterns
  (e.g., runaway Lambda executions, accidental NAT deployment)

---

## Architecture Decisions

1. **Tag-based cost allocation over account-per-env**: Single account with tag-based
   filtering is simpler for a lab. Production would use dedicated accounts per env.

1. **Email subscribers as placeholder**: Real implementation would use SNS → Lambda → Slack.
   Email addresses are placeholders for the Terraform structure.

1. **$100/mo dev budget**: Based on the idle cost analysis (~$52-65/mo running,
   ~$15-20/mo paused). $100 provides ~50% headroom for active development.

1. **$10 anomaly threshold**: Low enough to catch accidental deployments (NAT gateway = $32/mo)
   but not so low it triggers on normal daily variation.
